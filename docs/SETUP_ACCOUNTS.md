수집(목록 읽기)은 모두 **로그인 없이** 하므로 가입이 필요 없다. 아래는 **직접 응모할 때** 필요한 것.

## 자동 응모를 하지 않는 이유
확인한 사이트의 응모는 전부 로그인·외부 사이트·본인 인증이 필요하거나 계정 약관상 자동화가 위험한 방식이다.
비밀번호는 저장하지 않는 원칙이라, 이 경우 점수/마감과 함께 **알림으로 알려주고 직접 응모**하도록 했다.

## 봇 차단 사이트에 대해
퀘이사존·슈퍼투데이의 Cloudflare 차단이나 뽐뿌의 IP 차단을 우회하는 코드는 만들지 않았다(사이트 정책 존중).
이 사이트들이 꼭 필요하면, 본인 PC에서 직접 보거나 공식 RSS/앱 알림을 이용해야 한다.

## 응모 프로필 (폼 제출 단계용)
이름·전화·주소가 필요한 폼은 현재 자동 제출하지 않는다. 필요해지면 `PROFILE_NAME`, `PROFILE_PHONE`, `PROFILE_ADDRESS` Secrets로 받는다.
