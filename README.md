# giveaway-hunter

국내 경품·사은품 이벤트를 자동으로 모아 **텔레그램**으로 알려주고, 댓글 응모는 승인 후 대신 달아주는 도구. GitHub Actions에서 돌아가므로 PC가 꺼져 있어도 된다.

## 하는 일

- **유튜브(IT 유튜버)**: 설정한 채널 + **검색으로 찾은 소규모 채널**(구독자 적은 곳 우선, 이벤트를 연 채널은 자동 감시). 실제 이벤트(응모 링크 또는 다수 시청자의 같은 양식 댓글)만 `<유튜브> 이벤트 확정` 한 메시지로 묶어 알림 — 제품·기한·응모 방법·댓글 조건·경쟁(구독자/댓글 수)
- **보겸TV/보겸S**: 커뮤니티 게시물과 링크된 영상만 이벤트로 취급. 게시글 댓글 초안(키워드·줄 수 보장), 영상 양식은 답장으로 받아 초안 생성
- **승인 후 응모**: 댓글 초안 + [게시] 버튼 → 구독·좋아요·댓글 처리, 이미 쓴 댓글은 `검수`로 양식 확인·수정 제안, 응모 후 당첨 발표 감시
- 제외: 키보드(설정 가능), 마감 지난 이벤트, 회원가입·구매 조건 이벤트

## 시작하기

1. [docs/SETUP.md](docs/SETUP.md)의 순서대로 텔레그램 봇, YouTube API 키/OAuth, Anthropic 키, GitHub Secrets 등록
2. Actions → **collect** → Run workflow (처음엔 `reset_events` 체크)
3. 이후 매일 아침 8시(KST)쯤 자동 실행. 버튼 응답은 `watch`가 켜져 있는 동안 30~60초 안에 처리

## 구성

- 설정: `config/channels.yaml`(채널), `config/discovery.yaml`(발견 검색 쿼리), `config/filters.yaml`(키워드·제외 분야)
- 개발 가이드·확인된 사실·제약: [CLAUDE.md](CLAUDE.md)
- 초기 설계(Phase 0~5): [docs/PLAN.md](docs/PLAN.md) — 구현은 이후 커뮤니티 수집·발견·검수·watch 등으로 확장됨
